# LX-WMS 离线桌面仓库管理系统

LX-WMS 是一套支持完全离线运行的桌面级仓库管理系统，使用 Ant Design 构建 UI，基于 SQLite 存储数据，并支持 GitHub Releases 在线更新。

## 关键特性

- 完全离线可用（除更新检查外）
- 首次启动强制离线创建管理员账号，初始化后关闭注册入口
- Windows .exe 安装器，默认安装路径为 `C:\LX-WMS` 且可自定义盘符
- GitHub Releases 自动更新检测

## 功能清单

### 账号与权限

- 管理员初始化：首次启动离线创建管理员
- 用户管理：用户新增、启用、禁用、重置密码
- 权限控制：基于角色组的功能权限分配
- 个人资料：头像、手机号、邮箱维护

### 库存与基础数据

- 库存台账：按物料查看库存数量、出入库累计与结余
- 基础数据：物料分类、仓库、库位、供应商、项目维护
- 库存流水：记录关键出入库动作

### 入库管理

- 入库单创建与确认
- 采购入库与到货图片记录
- 库位与仓库信息维护

### 出库管理

- 出库单创建与审核
- 出库物品支持名称或型号模糊搜索
- 按项目关联出库记录

### 采购管理

- 采购申请、采购处理、到货、入库流转
- 预计单价与实际单价记录

### 报表分析

- 采购报表、入库报表、出库报表
- 项目消耗分析：物料清单、单价、金额汇总
- 库龄报表

### 系统与运维

- 本地缓存清理
- 自动更新检查
- 数据备份配置
- 邮件发信配置与测试

## 目录结构

```
electron/           Electron 主进程与本地数据库逻辑
electron/migrations SQLite 迁移脚本
src/                前端 UI
build/              安装器图标与构建资源
```

## 开发环境

1. 安装依赖（已内置 `.npmrc` 使用国内镜像）：

```bash
npm install
```

2. 启动桌面开发模式：

```bash
npm run dev
```

## 构建与打包

```bash
npm run dist
```

生成的 Windows 安装包输出在 `release/` 目录，默认安装目录为 `C:\LX-WMS`。
安装包命名格式为 `LX-WMS-Setup-当前版本号.exe`。

## 自动更新

- 更新源：GitHub Releases
- 请在发布时创建版本号 Tag，并上传安装包
- 更新逻辑由 `electron-updater` 驱动
- 国内默认使用镜像加速访问 Releases 下载

## GitHub 配置说明

请在 `package.json` 中配置正确的仓库地址：

- `repository.url`
- `build.publish.owner`
- `build.publish.repo`

## 安全说明

- 密码仅保存为强哈希（不可逆）
- 所有数据库操作均在本地完成
- 审计日志记录关键操作
